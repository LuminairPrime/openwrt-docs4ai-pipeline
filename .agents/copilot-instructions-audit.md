## Copilot Instructions Audit

Date: 2026-04-06

### Outcome

The `.github/instructions/` folder was reduced to a minimal Copilot-only
instruction set.

### What was checked

- `.github/instructions/` was compared against `.github/skills/`.
- There were zero true basename duplicates between the two Copilot roots.
- The real problem was not `.github/skills/` duplication. It was that
  `.github/instructions/` had become a second imported prompt surface full of
  broad `applyTo: "**"` overlays generated from `install-claude-skills.ps1`.

### What was removed

The removed files were imported skill-conversion overlays. Many explicitly
identified themselves as:

- `auto-generated by install-claude-skills.ps1`
- carrying `AbsolutelySkilled/AbsolutelySkilled` companion-install text

Those files overlapped heavily with the local Claude-style skill inventory under
`.agents/skills/` and created unnecessary prompt breadth in Copilot.

### What was kept

The instruction surface now keeps only the narrow, Copilot-native policy files:

- `github-actions-ci-cd-best-practices.instructions.md`
- `markdown.instructions.md`
- `markdown-accessibility.instructions.md`
- `python.instructions.md`
- `shell.instructions.md`
- `update-docs-on-code-change.instructions.md`

### Why this keep set

- They are filetype- or workflow-targeted, not broad imported skill catalogs.
- They fit the purpose of `.github/instructions/` better than the removed files.
- They reduce semantic duplication with `.agents/skills/` and lower prompt bloat.

### Policy going forward

- Treat `.github/instructions/` as a minimal instruction overlay surface.
- Treat `.agents/skills/` as the canonical local Claude-style skill source.
- Treat `.github/skills/` as retired; leave only the tombstone README.
- Do not repopulate `.github/instructions/` by converting generic skills into
  broad instruction files.

### Recovery

If any removed instruction file is needed later, recover it from git history
instead of re-running the importer.
