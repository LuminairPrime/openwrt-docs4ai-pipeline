# Draft Cookbook Workspace

This directory is the staging area for cookbook pages being authored through the v14 cookbook center.

Use it for:

- trusted-agent draft pages before promotion
- revisions that failed review and need another pass
- human review of the exact draft that is being proposed for `static/cookbook-source/`

Do not treat this directory as the live cookbook corpus.

## Naming Rule

```text
<cookbook-slug>-draft.md
```

Example:

```text
ucode-async-process-pattern-draft.md
```

Each draft should have a companion creation log under `../logs/` before promotion.
