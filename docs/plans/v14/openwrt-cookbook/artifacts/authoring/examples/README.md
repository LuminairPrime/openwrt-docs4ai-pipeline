# Authoring Example Packets

This directory holds concrete example authoring packets copied from real staged cookbook work.

Use these files when a blank template is too abstract and you want to see the expected shape of:

- a staged draft
- its companion creation log
- its prepared human review record

Current example packet:

- `ucode-native-file-io-and-json-draft.md`
- `ucode-native-file-io-and-json-creation-log.md`
- `ucode-native-file-io-and-json-review-record.md`

These are sample copies of the recently verified retroactive backfill packet for the
`ucode-native-file-io-and-json` page. They are reference examples only and are not
the authoritative live staging files.

For new work, still start from the blank templates and write the real active files under:

- `../drafts/`
- `../logs/`
- `../reviews/`
