## Scenario 27

```js
// LuCI JavaScript - call network.interface dump over ubus
var ubus = require('ubus');

ubus.connect().then(function(conn) {
    return conn.call('network.interface', 'dump', {});
}).then(function(data) {
    data.interface.forEach(function(iface) {
        if (iface.interface === 'lan') {
            var addrs = iface['ipv4-address'] || [];
            for (var i = 0; i < addrs.length; i++) {
                var addr = addrs[i].address;
                if (addr && addr !== '127.0.0.1') {
                    console.log('LAN IPv4:', addr);
                    return addr;
                }
            }
        }
    });
});
```

## Scenario 17

**OpenWrt ucode** is a lightweight, embeddable scripting language and runtime environment designed specifically for OpenWrt's constrained embedded environment.

**Why it was created:**
- The existing options (shell scripts, UCI configuration, Lua in LuCI) were either too heavy, too limited, or had unnecessary overhead for simple system tasks
- There was a need for a minimal interpreter that could handle configuration management, hotplug events, and system scripting efficiently on devices with limited RAM and CPU

**What it is good for:**
- Hotplug scripting (network interface changes, USB device events)
- Lightweight system management tasks
- Bridging between shell and more complex languages
- Fast startup and execution with minimal memory footprint
- Native JSON-like data structures
- Direct ubus and UCI integration without heavy dependencies

## Scenario 10

**Script to place in `/etc/rc.d/S99firstboot` (or `/etc/rc.local` for simpler execution):**

```sh
#!/bin/sh /etc/rc.common
# Run only on first boot - check if already configured
[ -f /etc/config/system ] && grep -q "timezone" /etc/config/system && exit 0

# Set default timezone to UTC
uci set system.@system[0].timezone='UTC'
uci commit system

# Apply immediately without reboot
/etc/init.d/system reload
```

**Alternative placement using `/etc/rc.local`:**

```sh

# Place this in /etc/rc.local
# Runs at the end of each boot - add your own guard for "first boot only"
```
